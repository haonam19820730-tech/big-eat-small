# 大吃小

越吃越大、大的可以吃小的。手機瀏覽器就能玩。

- 單人：對戰電腦
- 多人：開房間，把 4 碼房間號傳給朋友（最多 8 人）

## 怎麼玩

1. 拖動螢幕控制方向
2. 吃到點點會變大
3. 碰到比你小的就能吃掉
4. 被更大的撞到會被吃
5. 長按「加速」會變快，但體型會瘦一點

## 在電腦上先試

用瀏覽器打開 `index.html` 就能玩單人。

多人需要上網（用 WebRTC 連線），建議用本機伺服器：

```bash
npx --yes serve .
```

然後用手機跟電腦開同一個網址。一人按「開房間」，另一人按「加入房間」輸入 4 碼。

## 放到 GitHub Pages 給朋友玩

這是獨立專案，不要塞進你現有的兩個 repo。

1. 在 GitHub 開一個新 repository，例如 `big-eat-small`
2. 把這個資料夾推上去
3. 在 repo 的 Settings → Pages，Source 選 `main` 分支、`/ (root)`
4. 網址：`https://haonam19820730-tech.github.io/big-eat-small/`
5. 把網址傳給朋友，用手機打開即可

朋友若要一起玩：一人開房間，把房間號或「複製邀請」貼給對方。雙方都要開著這個網頁。
